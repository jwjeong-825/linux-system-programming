# Vi Editor

## What is Vi?

Vi는 Linux/Unix 환경에서 사용하는 텍스트 편집기이다.

터미널 환경에서 파일을 생성하거나 수정할 수 있다.

---

## Basic Modes

### Command Mode

기본 모드

- 커서 이동
- 저장
- 종료
- 삭제

등의 명령 수행

---

### Insert Mode

텍스트 입력 모드

진입:

```bash
i
```

---

## Basic Commands

### Save

```bash
:w
```

파일 저장

---

### Quit

```bash
:q
```

종료

---

### Save and Quit

```bash
:wq
```

저장 후 종료

---

### Force Quit

```bash
:q!
```

저장하지 않고 강제 종료
