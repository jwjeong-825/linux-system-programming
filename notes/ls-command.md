# LS Command

## What is ls?

ls는 Linux에서 파일 및 디렉토리 목록을 출력하는 명령어이다.

---

## Basic Usage

```bash
ls
```

현재 디렉토리 파일 목록 출력

---

## Options

### ls -l

상세 정보 출력

```bash
ls -l
```

출력 정보:
- file permission
- owner
- size
- modified time

---

### ls -a

숨김 파일 포함 출력

```bash
ls -a
```

---

### ls -al

전체 상세 정보 출력

```bash
ls -al
```
