# Shell

## What is Shell?

Shell은 사용자와 운영체제 커널 사이에서 명령을 전달해주는 인터페이스이다.

사용자는 shell에 명령어를 입력하고,
shell은 이를 해석하여 운영체제에 전달한다.

대표적인 shell:
- bash
- sh
- zsh

---

## Basic Commands

### pwd

현재 작업 디렉토리 출력

```bash
pwd
```

---

### ls

현재 디렉토리 파일 목록 출력

```bash
ls
ls -l
ls -a
```

---

### cd

디렉토리 이동

```bash
cd ..
cd ~
cd directory_name
```

---

### mkdir

새 디렉토리 생성

```bash
mkdir test
```

---

### rm

파일/디렉토리 삭제

```bash
rm file.txt
rm -r directory
```
